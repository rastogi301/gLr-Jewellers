💍 GLR Jewellers - Jewellery Store Website

A modern and responsive jewellery store website built using HTML, CSS, and JavaScript. This project showcases elegant gold jewellery collections with interactive features such as product search, shopping cart, dark mode, and responsive design.

✨ Features

- Responsive Design
- Modern Gold-Themed UI
- Home Page with Hero Banner
- Necklace, Bangles & Gold Rings Collection Pages
- Search Products
- Add to Cart Functionality
- Shopping Cart with Total Price Calculation
- Dark/Light Mode
- Mobile Friendly Navigation
- Customer Feedback Section
- Contact & Social Media Links
- Smooth Hover Animations
- WhatsApp Quick Contact Button

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts

🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
